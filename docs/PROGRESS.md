# Progress and title compatibility

This roadmap tracks outcomes a user can reproduce. The denominator for an instruction or interface is the identified guest build and tested set. A global “percent of Xbox emulated” has no defensible denominator. [Measured matrix](RESULTS.md) · [Machine-readable records](../evidence)

| Milestone | Status | Current evidence | Exit criterion |
|---|---|---|---|
| 0. Identify a package | Verified | Selects manifest entries and reads PE imports. The scanner preserved names and ordinals across 16 DLLs. The launcher selected Lanes by manifest ID and reported the absent retail executable. | Resolve title ID/entry selection and enumerate ordinary and delay imports. Verify a present synthetic entry and report a missing retail executable explicitly. |
| 1. Native process and memory | Partial | Rust XMem reserves and commits guest memory. It serves heap allocation and the title working-set query. The Linux guest passed on Valve Proton and GE-Proton. | Run the same guest bytes on physical Windows x64, Valve and GE. Require the expected state, alignment, release and guest exit status. |
| 2. Guest graphics submission | Partial | Submits command lists through Xbox device slots. A guest creates a device through profile 0x20002, submits two clears and checks 962 pixels plus guards. PresentX has a separate screen-sampling gate. See results by adapter and provider. | Create a device through a version-identified Xbox ABI, submit a command list through guest slots, render/present, and verify two ordered updates to the same resource. |
| 3. Retail shader and resource translation | Partial | Runs retail shaders on NVIDIA and AMD. Both adapters verified two graphics pipelines by pixel readback and the Nanite page-transcode compute shader by word-for-word comparison. The Xbox-facing depth/stencil control passed on both GPUs. The Nanite mesh shader still needs translation. | Translate one original retail compute kernel and one graphics pipeline. Check metadata, binding layout, every output and guards against independent references on two vendors. |
| 4. Playable platform services | Partial | Reads mouse, keyboard and XInput gamepads. Lanes runs as a manifest-selected homebrew game with XMem-backed state and a GPU-generated course. The replay checks successful and failed runs. | Check controller state and hotplug, audio channel routing via loopback, save/reload after restart and storage read completion through guest APIs. |
| 5. First retail title | Chase cinematic rendered | Frosty starts the sandbox intro in the Construct map. The 4K studio logo movie and the retail main menu appear on the captured display. A 12-minute 55-second desktop replay reached the chase dialogue. Real-time scenes remained near-black. | Record one supplied build hash, initialization, first correct frame, interactive input, a ten-minute replay and known defects on one host. |
| 6. Multi-title compatibility and performance | Pending | Awaits a second retail launch. The package inventory and graphics profile for other candidates appear below. Frame-time and memory-budget targets await title workloads. | Repeat the playable gate on three independently built retail titles across at least two engines. Track Linux and Windows separately, including Series S workloads and cold/warm frame-time distributions. |
